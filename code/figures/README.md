# Reconstructed archived-output figures

Five SVGs are new deterministic descriptive views of final saved summaries: truth acceptance, full-grid acceptance, median grid quadrature, grid RMSE and median-quantile raw rejection. They cover all matched design cells relevant to each view and do not add experiments. Two derived table views are under `results/views/`.

Reconstruct into a new external directory with the pinned reporting environment and `scripts/render_outputs.py`. Source data and displayed W3 numeric references remain separately preserved; these SVGs are not claimed pixel-identical to original paper graphics or silently substituted into W3. Their metadata omits dates and private paths and uses a fixed reporting identifier. Public rights to the underlying outputs and final release scope remain unconfirmed, so these files are for private review pending clearance.
