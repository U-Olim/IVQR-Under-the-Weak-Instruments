# Actual software and dependency boundary

**Verification:** Python 3.11, standard library only. `requirements.txt` has no third-party entries. `tests/` needs only unittest and the new verifier. Neither R nor research solvers are loaded by the verification scripts.

**New figure/table reporting:** `requirements-figures.txt` pins the actual Matplotlib/NumPy reporting environment and direct/transitive packages used during preparation. This is explicitly new reporting code over archived summaries; installing it is not an upgrade of historical R, a numerical-policy change or a claim that old simulations have been replayed. Exact SVG byte comparison has only been checked in the recorded preparation environment; platform/font differences may affect rendered bytes. Source scalar values and generated CSV tables can still be checked independently.

**Preserved research implementation:** recorded Windows R 3.4.3 (2017-11-30), quantreg 5.34, hdm 0.2.0, hqreg 1.4, mvtnorm 1.0-6, doSNOW 1.0.16, foreach 1.4.3, snow 0.4-2, iterators 1.0.8, and the recorded numerical/transitive dependencies. `config/historical_R343_versions.csv` preserves observed DESCRIPTION/normalized version fields; `historical_R343_installed_packages.csv` preserves the full recorded name/version/priority inventory. Personal installation-path columns are omitted in these documented metadata projections; originals are unchanged outside this selection.

`src/load_implementation.R` takes relative repository paths and an explicit historical extension-environment root, then calls the byte-preserved original environment guard before loading configuration and all six algorithm modules. The guard still checks exact R version, historical-library precedence and pinned package versions. There is no bundled portable historical runtime and no automatic fit or Monte Carlo launcher. Its load path was inspected statically; no R fit, simulation or installation was run in preparation.

The article's selected numerical diagnostics used historical E/F/G saved candidates, penalty/RNG records, exported arrays and exact certificates. Their minimal final summaries are included, but not the full numerical pipelines or large certificate archives. Authentic Stage 2F helpers were recovered and verified in prior preparation, and remain available in the separate preserved archive. Adding those helpers alone would not supply `stage2f/output/exact_face_20261029T102755Z/` or complete replay. The research library for the main archived experiment has no import of Stage 2F/2G: those are later diagnostic workflows, not hidden prerequisites for the supported verification commands. This minimal selection therefore excludes their executables, development traces and unused numerical configs rather than claiming a complete certification environment.

Original experiment/reporting launchers, their execution guards and historical files remain preserved in the source repository; none was rewritten or weakened. Do not bypass them or substitute current CRAN/solver versions to claim historical equivalence.
